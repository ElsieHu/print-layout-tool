# 打印排版工具

一个用于打印排版的可视化工具，支持图片上传、裁切线自动生成、拖拽排版、自动对齐磁吸、正反面联动排版，以及导出PDF。

**在线体验：** https://elsiehu.github.io/print-layout-tool/

## 功能概览

- **图片上传**：支持点击上传或拖拽图片到画布
- **自由排版**：拖拽移动、八方向调整大小
- **裁切线**：自动生成裁切线（出血标记），不覆盖图片内容
- **自动对齐**：拖拽时自动对齐到其他图片边缘/中心、画布边缘/中心
- **磁吸功能**：接近对齐线时自动吸附
- **多图片支持**：可上传多张图片，每张自动生成独立裁切线
- **正反面联动**：正面上传图片后，背面自动生成对应容器
- **翻页模式**：支持长边翻页（水平镜像）和短边翻页（垂直镜像）
- **PDF导出**：导出含裁切线的双面PDF

## 本地运行

由于浏览器安全策略，直接用 `file://` 打开可能无法正常工作。请使用本地HTTP服务器：

```bash
# 进入工具所在目录
cd "工具文件所在目录"

# 启动 Python HTTP 服务器
python3 -m http.server 8766

# 然后在浏览器中打开
# http://127.0.0.1:8766/index.html
```

按 `Ctrl+C` 停止服务器。

## 使用教程

### 1. 基本设置

打开工具后，在顶部工具栏进行设置：

| 设置项 | 说明 |
|--------|------|
| 纸张 | A4 / A3 / A5 / Letter / B5 |
| 方向 | 纵向 / 横向 |
| 翻页 | 长边翻页（像书本左右翻）/ 短边翻页（像日历上下翻）|
| 出血 | 裁切线与图片边缘的距离（默认3mm）|
| 磁吸 | 对齐吸附灵敏度（默认8px）|

### 2. 上传图片

有两种方式上传图片：

- **方式一**：点击右侧控制面板的"上传到正面"或"上传到背面"按钮
- **方式二**：直接将图片文件拖拽到画布上

上传后图片默认放在画布中央。

### 3. 移动和调整图片

- **移动**：鼠标按住图片拖拽
- **调整大小**：选中图片后，拖拽四角或四边的圆形手柄
- **精确调整**：选中图片后，在右侧"选中图片"面板输入精确的X/Y/宽/高数值（单位mm）
- **微调位置**：选中图片后，用键盘方向键移动（按住Shift大步移动）
- **居中**：点击"居中"按钮将图片放到画布正中
- **删除**：选中图片后按Delete键，或点击"删除图片"按钮

### 4. 裁切线

每张图片会自动生成裁切线（红色L形角标记），位于图片外侧出血距离处。

- 在工具栏勾选/取消"裁切线"来显示/隐藏
- 修改"出血"值调整裁切线与图片的距离
- 裁切线不会覆盖图片内容

### 5. 自动对齐与磁吸

拖拽图片时，系统会自动检测对齐目标：

- 画布的左边缘、中心线、右边缘
- 画布的上边缘、中心线、下边缘
- 其他图片的左/中/右边缘
- 其他图片的上/中/下边缘

当图片接近对齐目标时（距离小于磁吸阈值），会自动吸附并显示蓝色辅助线。

### 6. 正反面联动

这是本工具的核心功能，用于双面打印排版：

1. 在**正面**画布上传并排版图片
2. 工具会自动在**背面**画布生成一个相同大小的容器（虚线框）
3. 背面容器的位置根据翻页模式自动计算：
   - **长边翻页**：背面容器水平镜像（左右翻转位置）
   - **短边翻页**：背面容器垂直镜像（上下翻转位置）
4. 点击背面容器中的"点击上传背面图片"可上传背面对应图片
5. 移动正面图片时，背面容器会自动跟随联动
6. 调整正面图片大小时，背面容器也会同步调整

### 7. 翻页模式说明

双面打印时，纸张的翻页方向决定了背面的方向：

```
长边翻页（像书本）          短边翻页（像日历）
┌──────┐    ┌──────┐       ┌──────┐
│ 正面 │    │ 背面 │       │ 正面 │
│      │ -> │      │       │      │
│      │    │      │       ├──────┤
│      │    │      │       │ 背面 │
└──────┘    └──────┘       │      │
  左右翻                     └──────┘
                             上下翻
```

- **长边翻页**：背面内容水平镜像，适合书本式装订
- **短边翻页**：背面内容垂直镜像，适合日历式装订

### 8. 导出PDF

点击右上角"导出PDF"按钮：

- PDF第一页为正面内容
- PDF第二页为背面内容
- 包含所有裁切线
- 纸张尺寸与设置的纸张一致

## 常见问题

### Q: 导出的PDF中图片质量下降？
A: PDF导出使用原始上传图片，质量取决于上传图片的分辨率。建议使用高分辨率图片。

### Q: 背面容器可以单独移动吗？
A: 背面容器默认跟随正面联动。如果背面已上传图片，可以单独移动背面图片，但容器位置仍跟随正面。

### Q: 如何取消背面的图片但保留容器？
A: 点击右侧控制面板的"清空背面"按钮，会移除背面图片但保留联动容器。

### Q: 裁切线是什么？为什么需要？
A: 裁切线（Crop Marks）是打印行业标准的裁切标记，指示印刷后裁切的位置。打印时图片需要超出最终尺寸（出血），裁切线标记裁切边界，确保裁切后没有白边。

### Q: 支持哪些图片格式？
A: 支持 PNG、JPEG、WebP 等常见图片格式。

## 技术说明

- 纯前端实现，无需后端
- PDF导出使用 [jsPDF](https://github.com/parallax/jsPDF) 库
- 所有图片处理在浏览器本地完成，不上传到服务器
